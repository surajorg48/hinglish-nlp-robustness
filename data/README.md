# Dataset provenance

No raw dataset is stored in this repository at this stage.

The selected datasets, access routes, licenses/terms, split definitions, and download instructions will be documented here after the literature and dataset audit is complete.

## Required provenance fields

For every dataset used in the study, record:

- Official dataset name
- Original provider/project
- Canonical URL or paper
- Dataset version, if applicable
- Access date
- License or terms of use
- Number of examples actually used
- Label definitions
- Official train/validation/test split, if provided
- Any filtering performed
- Any deduplication performed
- Any transformations/perturbations applied
- Whether redistribution is permitted

## Data handling rule

Raw data must not be committed merely for convenience. If a dataset has redistribution restrictions, provide a reproducible download/access procedure instead.
